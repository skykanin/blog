# Personal Blog
[![Deploy GitHub Pages](https://github.com/skykanin/blog/actions/workflows/deploy-pages.yaml/badge.svg)](https://github.com/skykanin/blog/actions/workflows/deploy-pages.yaml)

Personal blog for random stuff built using hugo

## Development

This repo provides a nix flake with all required tooling. To build this project run

``` sh
make build
```

To develop this project run

``` sh
make dev
```
